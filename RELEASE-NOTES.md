# FlightRadar v7.3.6

The first packaged FlightRadar build includes the updated METAR dashboard, radar and flight board, aircraft details and optional photos, and touchscreen or phone setup.

Open `FlightRadar/FlightRadar.ino` with the documented Arduino libraries and install the matching TFT_eSPI setup before compiling. Use the Huge APP partition on a 4 MB classic ESP32. New installations start with a public airport as their example radar center. Set your preferred location in Settings.

The flight feed is subject to the provider's unkeyed quota. See the data sources guide for attribution and current limits.
